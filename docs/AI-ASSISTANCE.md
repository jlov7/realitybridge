# AI assistance and review boundary

OpenCode and Codex assisted the design, implementation, documentation, testing, and review of RealityBridge. The finite study's cases, evaluator, and reference-handling code were AI-authored. The later ordinary comparator and its raw-trace adjudication received AI cross-review. That review is useful for finding inconsistencies, but it is **not independent human replication** or validation by an unaffiliated team.

The repository retains source hashes, protocols, raw observations, failed attempts, amendments, and offline replayers so readers can inspect the claims and rerun the saved-data calculations. These records support the stated local results; they do not establish that every implementation or interpretation is correct. A reader who finds a mismatch should report the exact source/receipt, case, response and state channel, and observed evidence using [Contributing](../CONTRIBUTING.md).

Codex also authored the next-increment mutation families, synthetic tasks,
review packet, runner code, and result note. The review capsule has not been
classified by an outside person. The matched-request discovery exercise was
written by the same AI project team on both sides, and the repair worker chose
only among prewritten transformations. These limits apply even where local
tests and raw-trace replay pass.
