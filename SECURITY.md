# Security reporting and supported scope

RealityBridge is local research software for synthetic data and a disposable loopback Gitea reference. It is not a production service or a sandbox for untrusted general code. The macOS `sandbox-exec` test covers one staged repair worker and denied read path; it does not prove network-layer egress denial or general container isolation.

For a sensitive finding, use [private vulnerability reporting](https://github.com/jlov7/realitybridge/security/advisories/new) when the host makes it available. If it is unavailable, do not post exploit details or credentials in a public issue; open a nonsensitive issue asking for a private contact route.

Supported security updates cover the maintained source candidate and its six-operation local workflow. Historical raw receipts and source snapshots are immutable evidence; corrections are new labeled records. Depend on the exact pinned reference digest and verify source/receipt identity before interpreting an experiment.
